# Windows List
This add-on uses to show a windows list dialog.

## Usage
This add-on provides an unassigned gesture in NVDA's input gestures dialog to open a window list dialog that lists the windows currently on the screen.  
You can assign it a gesture by going to NVDA Menu > Preferences > Input Gestures... > Windows List > Show windows list dialog.  
You can then use the gesture you just assigned to open the windows list dialog.  
In a dialog, up - down arrows to move through open windows, enter to focus on that window, escape to close the dialog. You can also tab  to the OK and Cancel buttons.
